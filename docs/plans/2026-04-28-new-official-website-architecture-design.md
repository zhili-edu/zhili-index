# 新官网架构设计文档

> 状态：当前定稿提案（架构确认版）  
> 分支：`core/new-official-website-react-architecture`  
> 范围：仅梳理官网架构、信息结构、技术方向、内容组织与视觉原则；**不包含实际代码编写**。

---

## 1. 项目背景

当前仓库并不存在可直接继承的 Vue 官网工程，也没有现成的 React 官网骨架。仓库现阶段主要承载素材与规划内容，核心参考文档为：

- `执理官网内容素材整理.md`

基于该现状，本次工作不采用“Vue 到 React 的局部迁移”思路，而采用“以 React 体系重新定义官网架构”的方式推进。

---

## 2. 项目目标

新官网目标不是搭建一个单纯的品牌展示页，也不是做成软件外包接单站，而是建立一个具备以下能力的对外主站：

1. 统一执理教育科技的品牌表达。
2. 清晰承载学校、职教、教育集团、研学与文旅合作场景。
3. 呈现“教育根基 + 技术能力 + 合作背书 + 未来方向”的完整叙事。
4. 为后续 React 官网开发、内容沉淀、案例扩展和品牌升级提供稳定的架构基线。

---

## 3. 官网定位

### 3.1 主身份

推荐官网唯一主身份为：

> **执理教育科技｜AI 驱动的计算机教育科技公司**

### 3.2 官网主叙事

官网需要传达的不是“培训班”“外包团队”或“单点工具产品”，而是：

- 有真实教育场景沉淀的教育科技团队
- 具备平台研发与 AI 应用能力的技术团队
- 能服务学校、职业院校、教育集团、区域教育与场景运营合作方的综合型团队

### 3.3 对外表达边界

官网应聚焦教育科技主线，不应将以下方向放在首页核心位置：

- 融资金额、估值、股权细节
- 现金流和经营压力
- 内部协作流程和员工生活信息
- “承接各种软件定制开发”的外包表述
- 未正式明确落地的合作项目归属

---

## 4. 架构方向结论

本次推荐采用：

## 方案 A：品牌主站 + 解决方案官网一体化

### 选择原因

1. 与现有素材最匹配，内容完整度最高。
2. 能统一品牌形象，避免业务线分散。
3. 适合官网第一版，便于后续逐步扩展。
4. 能自然承接“科技感 + 大气美观”的品牌视觉要求。

### 不采用的方向

#### 方案 B：集团生态展示站

不作为第一版主方案。原因是会让执理教育科技主身份被稀释，业务呈现容易过散。

#### 方案 C：纯产品矩阵官网

不作为第一版主方案。原因是会削弱执理现阶段最重要的“真实教育根基”和“合作场景可信度”。

## 5. 技术路线结论

虽然本次不编写实际代码，但官网未来技术架构方向应明确为：

> **React + Next.js**

### 选择原因

1. 官网天然需要更好的 SEO 能力。
2. 支持首屏性能优化、静态生成和内容型页面组织。
3. 后续如接入内容管理、表单系统、案例库、多语言，将具备更强扩展性。
4. 更适合承载品牌官网与解决方案型官网，而不是仅作为单页 SPA。

### 技术原则

- 先定内容和页面架构，再进入组件与开发实现。
- 内容优先于动效，品牌优先于炫技。
- 首页与一级页面需保证结构清晰、信息层级明确。
- 后续实现阶段应优先保证 SEO、首屏可读性和品牌表达一致性。

第一版官网建议采用以下 7 个一级页面：

1. 首页
2. 解决方案
3. 产品与平台
4. 案例成果
5. 合作伙伴
6. 关于我们
7. 联系我们

### 6.1 首页

承载品牌第一印象、核心业务概览、可信背书与转化入口。

### 6.2 解决方案

作为业务主线承载页，统一展示四大业务方向。

### 6.3 产品与平台

展示平台能力、技术产品与数字化系统能力。

### 6.4 案例成果

展示教育合作、教材、赛事、平台交付与场景案例。

### 6.5 合作伙伴

展示合作单位、授权背书与生态协同关系。

### 6.6 关于我们

讲述发展脉络、核心团队、组织能力与资质荣誉。

### 6.7 联系我们

面向不同合作对象提供明确联系入口与合作导向。

## 7. 业务结构设计

“解决方案”页建议采用四大方向结构，与素材文档保持一致：

1. **K-12 信息学奥赛与人工智能教育**
2. **职教 AIGC 实训平台**
3. **区域教育平台与场景运营**
4. **科技研学与文旅数字化场景**

### 7.1 K-12 信息学奥赛与人工智能教育

作为最强教育根基，用于证明执理的长期教研、培训、课程与平台能力。

### 7.2 职教 AIGC 实训平台

作为未来增长和技术想象空间最强的板块，用于体现 AI 方向的前瞻性。

### 7.3 区域教育平台与场景运营

用于体现与教育集团、区域教育场景、政府/国企协同能力。

### 7.4 科技研学与文旅数字化场景

作为教育能力的延展与数字化交付能力证明，不作为首页主身份，但作为案例和能力补充展示。

## 9. 未来 React 官网的结构分层建议

虽然当前不实现代码，但未来 React 项目应从架构上分为 5 层：

### 9.1 App Shell 层

承载全局结构，包括：

- 顶部导航
- 页脚
- 全局品牌氛围
- 全局 CTA
- 主题与布局框架

### 9.2 Page 层

承载每个一级页面的整体编排：

- 首页
- 解决方案页
- 产品与平台页
- 案例页
- 合作伙伴页
- 关于我们页
- 联系我们页

### 9.3 Section 层

承载页面区块模块，例如：

- Hero
- 数据背书模块
- 业务卡片模块
- 时间轴模块
- 案例矩阵模块
- 团队介绍模块
- 资质荣誉模块
- 联系 CTA 模块

### 9.4 Content Model 层

将当前素材文档拆分为结构化内容来源，例如：

- 品牌介绍
- 愿景使命
- 业务方向
- 产品清单
- 案例清单
- 合作伙伴清单
- 团队资料
- 荣誉资质
- 联系方式

### 9.5 Design System 层

统一后续组件实现与视觉表达标准，包括：

- 颜色体系
- 字体层级
- 间距系统
- 卡片样式
- 按钮体系
- 时间轴与数据展示组件
- 品牌图形语言

## 10. 内容模型建议

后续正式开发前，应先将 `执理官网内容素材整理.md` 拆解为以下内容域：

1. **Brand**：品牌定位、愿景、使命、一句话介绍
2. **Solutions**：四大业务方向内容
3. **Products**：学习平台、AIGC 平台、研学平台、文旅中台
4. **Cases**：学校合作、教材、赛事、平台案例
5. **Partners**：合作伙伴和背书单位
6. **About**：发展脉络、团队、组织能力、资质荣誉
7. **Contact**：联系人、联系场景、入口分类

这样做的价值是：

- 便于 React 页面模块复用
- 便于未来接入 CMS 或 JSON/YAML 内容源
- 便于后续做多语言版本和案例扩展

## 11. 视觉风格原则

官网视觉方向建议定义为：

> **科技感、大气、可信、克制的教育科技品牌官网**

### 11.1 视觉关键词

- 深色底
- 蓝青渐变
- 留白充足
- 层级清晰
- 轻量数据感图形
- 未来感但不过度赛博化

### 11.2 品牌气质要求

- 不做少儿培训班风格
- 不做外包接单站风格
- 不做过度娱乐化文旅站风格
- 要体现“教育科技基础设施建设者”的气质

### 11.3 动效与装饰原则

- 动效服务于品牌表达，不喧宾夺主
- 首页第一屏可适度使用光效、渐变、网格、粒子或数据线条
- 一级页面内部动效应强调秩序感与专业感

`core/new-official-website-react-architecture` 分支作为新官网核心分支，当前阶段承担的职责为：

1. 沉淀官网信息架构

- 不编写 React 页面代码
- 不搭建实际 Next.js 工程
- 不输出组件实现细节

- 不接入 CMS、表单、接口或部署流程

## 15. 结论

新官网第一版建议正式定义为：

> **执理教育科技官网：AI 驱动的计算机教育科技公司**

它不是旧 Vue 站点的改造项目，而是一个基于 React 体系重新建立的品牌官网与解决方案官网。当前架构基线以“教育科技”为唯一主线，以“四大业务方向”为核心承载，以“科技感 + 大气美观 + 可信专业”为视觉原则，为后续正式开发提供统一方向。
